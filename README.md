# 🚀 Windows Minh-Nexus OS

Chào mừng bạn đến với hệ điều hành **Windows Minh-Nexus** - phiên bản Windows tương lai chạy trực tiếp trên GitHub!

## 🌟 Giới thiệu
Đây là dự án "GitHub trong GitHub" độc đáo được phát triển bởi **Đỗ Đức Minh**, một lập trình viên nhí lớp 3B trường TH&THCS Vĩnh Tân, Biện Thượng, Thanh Hóa.

## ✨ Tính năng nổi bật
- **Giao diện Nexus:** Thiết kế hiện đại, bo góc, mang hơi hướng tương lai.
- **Recursion (Đệ quy):** Trải nghiệm GitHub bên trong chính GitHub.
- **Bản quyền Biện Thượng:** Mang đậm dấu ấn quê hương Thanh Hóa.
- **Chế độ "Vượt rào":** Tối ưu hóa cho các bạn học sinh lớp 3B giải trí sau giờ học.

## 🛠️ Công nghệ sử dụng
- HTML5 / CSS3
- JavaScript
- GitHub Pages
- Tình yêu với Nem chua và Minecraft! 🍖🎮
